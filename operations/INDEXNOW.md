# IndexNow release checklist
Development only until owner approves merge after audit. Public verification key is intentionally public. Confirm live key URL and sitemap. Repository variable INDEXNOW_ENABLED must be true for live sends; no production variable changes made. Run manual workflow on main for initial seed; default is dry run. Pushes to main notify changed, added and removed static sitemap URLs. Deployments that are not yet available fail safely; rerun after deployment. HTTP 200/202 means accepted or pending key validation, not indexed. Check Bing IndexNow dashboard. Dynamic D1 job events are not covered by this static workflow; add durable event queue when job SEO is enabled. Never notify preview/private URLs. No Google submission via IndexNow.
