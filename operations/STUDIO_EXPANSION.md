# Studio expansion workflow
Export candidate JSON from existing operator Career Sources tab. Independently review official website, career source, creative scope and actual office/contact pages. Vacancy cities are hints, not offices. Preserve firm-first coverage of reputable smaller-market studios.
Prepare a review array with careerURL, decision ("approve"), identityEvidence, officeEvidenceReviewed, creativeScopeReviewed and record (published registry schema). Use real review dates. employerVerified remains false.
Run node operations/review-studio-candidates.mjs candidates.json reviews.json staging.json. Output is a new staging file only; incomplete exports rejected. Inspect results, separately approve registry changes, run geography/profile/index generators and --check commands, test Preview routes and sitemap. Resolve city slug collisions and geographic matcher coverage before publishing.
No automatic publication or D1 writes. URL checks validate consistency, not evidence truth. ATS domains and identity conflicts require manual review. Outreach holds remain in force. Prior audits on initial feed, crawlability and application friction are historical release QA inputs; verify current Preview interactively, preserve owner preference against loading copy.
